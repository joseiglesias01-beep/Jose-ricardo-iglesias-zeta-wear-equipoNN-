# Zeta Wear · Dashboard & Escaparate ABC × XYZ

Este repositorio contiene la aplicación e infraestructura de análisis de catálogo para Zeta Wear (Lab de Agentes - UIE).

## Estructura

- `index.html`: Dashboard web autocontenido (HTML5, CSS3, JS) que muestra la matriz 3×3 ABC × XYZ, permite la exploración interactiva por celdas y destaca las referencias críticas (AZ y AY).
- `resultados/`: Ficheros CSV con la clasificación y políticas de inventario (`clasificacion.csv`, `abc.csv`, `xyz.csv`, `politicas.md`).
- `zeta-wear-lab/zeta-wear-lab/`: Código fuente de los scripts de análisis y tests de infraestructura.

## Despliegue en Vercel

El archivo `index.html` en la raíz permite el despliegue automático estático en Vercel.
